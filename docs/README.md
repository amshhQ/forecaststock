# Dokumen Proyek

Dokumen teknis yang menjadi bukti MK Software Development Life Cycle.

| Folder | Isi |
|---|---|
| `sdlc/` | SRS, test plan, rencana rilis, estimasi & risk register |
| `sdlc/requirements/` | Pertanyaan & rekap kuesioner, analisis aplikasi sejenis |
| `uml/` | Use case, ERD, activity, sequence diagram |
| `adr/` | Architecture Decision Record (ADR-000 dst.) |

Diisi mulai tahap perancangan (lihat rencana sprint di catatan semester 1, file 07).
